# Optional drafting templates

Adapt these examples to the argument. Leave unknown values as placeholders.

## Story and teaser

```text
We investigate [question] because [gap supported by prior work]. Using
[method/data/analysis], we find [observed result] under [bounded setting].
```

```text
Figure plan: [question it answers] -> [content needed] -> [supported takeaway].
Choose a schematic, plot, or example according to what makes the argument clear.
```

## Evidence tables and cases

```markdown
> **Table X.** [Comparison setting, metric direction, and claim supported.]

| System | [Metric] | [Uncertainty, if measured] |
| --- | ---: | --- |
| [Baseline] | [value] | [value] |
| [Proposed] | [value] | [value] |
```

Choose cases that explain a finding or limitation. Show the relevant input,
outcome, and interpretation; label excerpts and locate fuller evidence when
needed to assess the case.

## Section skeleton

- Introduction: question and gap -> approach -> findings and contribution.
- Method: task/input-output -> design -> constraints -> role in the claim.
- Evaluation: setting and metrics -> main result -> checks that explain it.
- Abstract and conclusion: one compact, supported argument; introduce no new
  result in the conclusion.

Keep citations and evidence locators next to the claims they support.
