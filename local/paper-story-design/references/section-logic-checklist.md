# Section and experiment logic

Use only the rows relevant to the current paper.

| Area | Minimum question |
| --- | --- |
| Introduction | Is the capability gap and contribution clear without implementation detail? |
| Related work | Are categories organized by the paper's distinction rather than by name-dropping? |
| Method | Are inputs, outputs, constraints, and module roles defined only where needed? |
| Data/benchmark | Are construction, quality control, splits, leakage, and difficulty reproducible? |
| Evaluation | Do metrics measure the claimed capability and define invalid outputs/fairness? |
| Experiments | Do main results, ablations, and analysis each answer a stated question? |
| Case study | Does each case show observable input, output, score/error, and insight? |
| Conclusion | Does it restate supported claims without introducing new evidence? |

For each section, identify one core point, its strongest evidence, and one
remaining limitation. Do not force a fixed paragraph count or add a subsection
solely to satisfy a template.
