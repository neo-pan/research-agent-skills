# Rebuttal response structures

Treat these as adaptable shapes, not venue requirements.

## Reviewer-specific response

```md
**[Reviewer ID / neutral concern heading]**

**Response.** [Direct answer in one sentence.] [Evidence with section/table/
figure locator, setting, and result.] [Bounded clarification or revision.]
```

Repeat the concern heading only when the next issue has a distinct claim or
resolution. Preserve the reviewer's substantive question while removing
unnecessary adversarial wording.

Greetings, thanks, and discussion invitations are optional; omit them when
they add little or consume a tight word budget.

## Global response

Use this only when the venue accepts an AC/global summary; keep reviewer-specific
answers separate below it:

```md
The main concerns are [A] and [B]. [Direct answers and supporting evidence.]
[Remaining limitation or revision, if relevant.]
```

For a small, naturally parallel comparison, use a table with the setting,
metric, and result. Explain the table in prose; do not turn the whole response
into a table. Apply the current venue and stage rules to citations, identity,
and external links.

## Concern map

| Concern | Direct answer | Evidence locator | Remaining uncertainty | Revision/experiment |
| --- | --- | --- | --- | --- |
| [claim] | [answer] | [Section/Table/Figure] | [scope] | [bounded action] |

## Private note to an area chair

Use only for a material, verifiable factual mismatch or evaluation inconsistency:

```md
[Review claim] appears inconsistent with [Section/Table/Figure], which reports
[specific fact]. This affects [material assessment point]. We ask that this
evidence be considered when assessing that point.
```

Do not speculate about reviewer motives or request that a review be ignored.
