# Rebuttal response structures

Treat these as adaptable shapes, not venue requirements.

## Reviewer-specific response

```md
Dear Reviewer [ID],

Thank you for the careful review. We address the remaining points below.

> **[Neutral concern heading]**

**Response.** [Direct answer in one sentence.] [Evidence with section/table/
figure locator, setting, and result.] [Bounded clarification or revision.]
```

Repeat the concern heading only when the next issue has a distinct claim or
resolution. Preserve the reviewer's substantive question while removing
unnecessary adversarial wording.

Cover every substantive weakness or question once. Merge items only when they
share both evidence and resolution; otherwise keep separate headings. A short
heading is enough (`Ablation of the routing module`), but the first response
sentence must answer the concern directly. Begin each reviewer-specific reply
with a brief thanks and end with a restrained invitation to continue discussion.

## Global response

Use this only when the venue accepts an AC/global summary; keep reviewer-specific
answers separate below it:

```md
Dear Area Chair and Reviewers,

Thank you for the careful reviews. The main concerns are [A] and [B]. We
address them with [evidence], while keeping the scope of the submitted claims.
```

For a small, naturally parallel comparison, use a table with the setting,
metric, and result. Explain the table in prose; do not turn the whole response
into a table. Cite only real, relevant, venue-allowed work, without external
links in an anonymous response.

## Private note to an area chair

Use only for a material, verifiable factual mismatch or evaluation inconsistency:

```md
Dear Area Chair,

Thank you for coordinating the review. We respectfully note that [review claim]
appears inconsistent with [Section/Table/Figure], which reports [specific fact].
We do not intend to dismiss the review; we ask only that this factual context be
considered when weighing the assessment.
```

Do not speculate about reviewer motives or request that a review be ignored.
